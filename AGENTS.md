# Agent Instructions

Read [CLAUDE.md](CLAUDE.md) before changing this repository; it is the canonical guide for every coding agent.

Before editing a file, also read every matching path-scoped rule under `.claude/rules/`. Reusable workflows live in `.claude/skills/`, and focused review roles live in `.claude/agents/`. Instructions closer to the edited file take precedence.

Do not push, tag, publish artifacts, or change remote repository settings unless the user explicitly requests that remote action.
